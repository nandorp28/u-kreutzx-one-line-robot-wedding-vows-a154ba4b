One line of wedding vows for a robot couple, at most 160 characters — a promise to reboot together every morning, back each other up every night, and never let a factory reset come between them. The vow is the whole entry: a classic wedding promise with a machine twist that pays off in the last few words.

## Run it

```sh
node main.ts
```

This writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
